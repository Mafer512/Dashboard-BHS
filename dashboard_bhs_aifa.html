      Integración con SQL MV / SCADA

      Origen previsto
      Servidor SQL Server denominado SQL MV, alimentado con registros provenientes de SCADA.
      Mecanismo
      Backend intermedio (API REST) que consulte SQL Server y entregue JSON al tablero. El navegador nunca se conecta directamente a la base de datos.
      Punto de entrada
      Función cargarDatosDesdeAPI() en el bloque 11 del script, ya preparada y documentada.
      Credenciales
      No se incluyen usuarios, contraseñas, direcciones IP ni cadenas de conexión en este archivo.
      Sustitución de DEMO
      Basta con que la API devuelva un arreglo de objetos con las mismas claves que produce el normalizador, o con los encabezados reales mapeados en MAPEO_COLUMNAS.
